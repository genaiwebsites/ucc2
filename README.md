# Usha Commercial Corporation (UCC) — Enterprise Website

> **Precision polymers & heavy industrial chemicals distribution since 1969.**

A modern, pixel-perfect, enterprise-grade web application built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, **Motion**, and **Phosphor Icons**.

---

## 🌟 Key Features

- **High-Performance Architecture**: Static site generation (SSG) with zero-layout-shift font optimization (`next/font/google` with `Onest` & `Inter`).
- **Certified Raw Material Catalog**: Filterable catalog covering Synthetic Elastomers (SBR, NBR, EPDM, PBR), Natural Rubber (RSS, ISNR), Furnace Carbon Black (N220, N330), and Vulcanizing Additives (CBS, TBBS, ZnO 99.5%, Stearic Acid).
- **Instant Search & Filter**: Real-time multi-field search across product titles, CAS numbers, standards, and compounding applications.
- **Interactive Technical Spec Modal (TDS / COA)**: Deep technical data sheet viewer with ASTM testing protocols and quick lot requisition.
- **Direct Procurement RFQ Desk**: Interactive quote requisition form with client validation, product auto-prefill, and status feedback.
- **Dual-Track Marquee**: Continuous infinite marquee showcasing global petrochemical principals and institutional clients.
- **Strategic Logistics Hubs**: Warehousing network overview for Dankuni Logistics Park, Taratala Urban Depot, Kolkata Port Terminal, and Jamshedpur Supply Corridor.
- **Enterprise SEO & Structured Data**: Dynamic `sitemap.xml`, `robots.txt`, OpenGraph metadata, and Schema.org `LocalBusiness` JSON-LD markup.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack, App Router)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: Motion (`motion/react`)
- **Iconography**: `@phosphor-icons/react`

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.

### 3. Production Build
```bash
npm run build
npm run start
```
